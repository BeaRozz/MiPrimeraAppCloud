# Mi Primera App Cloud

## Requisitos
<ul>
    <li>Docker compose
</ul>

## Levatar el proyecto

Para levantar el proyecto usar comando docker compose up en la terminal
```
docker compose up
```
Una vez ejecutado, en un navegador puede ingresarse como url: localhost o 127.0.0.1 <br>
En caso de usar otro puerto puede agregarse como :número de puerto.
